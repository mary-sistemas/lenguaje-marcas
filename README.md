# Lenguaje de Marcas

Trabajos del módulo de Lenguaje de Marcas y Sistemas de Gestión de la Información, 1º ASIR (IES Juan de la Cierva).

## Web ZeroWaste

Página web para organizar los alimentos de casa (nevera, despensa y frutero), ver cuándo caducan y tirar menos comida.

**Ver la web:** [ZeroWaste](https://mary-sistemas.github.io/lenguaje-marcas/pagina_web/)

- **HTML:** estructura semántica (header, nav, main, section, aside, footer), tablas, formularios, imágenes y vídeo.
- **CSS:** colores a partir del logo, fuentes, bordes, Box Model, pseudoclases (hover, active, focus) y pseudoelementos (first-letter, after).

Es la continuación de ZeroWasteML, el lenguaje de marcas que inventé en la Unidad 1.

## Actividades

- **UT1.1:** investigación inicial sobre los lenguajes de marcas.
- **UT1.2:** ZeroWasteML, un lenguaje de marcas inventado para el inventario de alimentos y recetas, con fechas de caducidad.

## Estructura

- `pagina_web/`: la web ZeroWaste.
- `actividades/`: las actividades en PDF.
